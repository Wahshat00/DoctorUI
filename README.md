# فرانت‌اند درمان‌یار

## اجرا
1. فایل‌های این پوشه را نگه دار.
2. در `config.js` آدرس FastAPI را تنظیم کن. مقدار پیش‌فرض `http://127.0.0.1:8000` است.
3. بک‌اند را اجرا کن.
4. این پوشه را با افزونه Live Server در VS Code باز کن.
5. صفحه کاربران: `index.html` و پنل مدیریت: `admin.html`

## مسیرهای مورد استفاده
- `GET /doctors`
- `POST /create-doctor`
- `DELETE /doctors/{id}/delete`
- `POST /doctors/{doctor_id}/reserve`
- `POST /ask-ai`

## نکات مهم برای هماهنگی با بک‌اند
- پنل کاربر انتظار دارد پاسخ `GET /doctors` شامل فیلد `schedule` باشد و هر زمان حداقل `start` و `is_reserved` داشته باشد؛ `end` اختیاری است.
- مدل `DoctorCreate` فعلی فیلدی برای ساخت برنامه کاری (schedule) ندارد. بنابراین از پنل فعلی نمی‌توان زمان‌های جدید تعریف کرد. برای تکمیل سیستم، endpoint مدیریت برنامه کاری/زمان‌های پزشک لازم است.
- مسیر `ask-ai` در بک‌اند باید با اسلش شروع شود: `/ask-ai`. همچنین فرانت‌اند فرض می‌کند بدنه درخواست یک JSON string ساده است.
- این پنل مدیریت فقط از نظر ظاهری جداست و احراز هویت ندارد. endpointهای مدیریتی را بدون authentication در اینترنت منتشر نکن.
- اگر فرانت‌اند و بک‌اند روی origin/port متفاوت هستند، CORS را در FastAPI فعال کن.
- حذف پزشک در بک‌اند باید واقعاً `session.delete(doctor_from_db)` و `session.commit()` را اجرا کند.
- endpoint رزرو باید در برابر درخواست‌های هم‌زمان نیز امن باشد تا یک زمان به دو نفر فروخته نشود.
